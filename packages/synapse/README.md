# 会话地图（Synapse）使用说明

Amadeus 右侧「会话地图」标签页里那张「对话关系图」。默认是**分层的环状视图**：先看项目（超级点），点开才展开某个项目的会话。

> 一句话：**概览只显示项目；点一个项目 → 它变成一个环；在环上用 ↑↓ 转着挑，选中就呼出它跨项目的关系；想打开某个对话就双击它。**

---

## 1. 基本概念

| 名词 | 含义 |
|---|---|
| **超级点** | 一个项目（工作区）= 一个点，显示「项目名 · 对话数」。 |
| **聚合线** | 概览时项目与项目之间的连线（线宽≈关联条数）。 |
| **环** | 展开项目后，它的对话排成的一个圆环。 |
| **选择框** | 环最顶上那个虚线小圈；**框住的那个=当前选中**。 |
| **最新点** | 该项目里最后聊过的对话，带一圈**浅色光晕**（默认它就在最顶上）。 |
| **聚焦** | 单击某个对话后，把它跨项目的关联点「呼」出来看。 |

---

## 2. 概览（全部收起时）

- 看到若干**超级点**（每个项目一个）+ 项目之间的**聚合线**。
- 底部**图例**：每个项目一条，点颜色圆点可**改颜色**，点名字可**显示/隐藏**该项目。
- 顶栏按钮：
  - **重排**：重新铺开布局。
  - **AI 连线**：让 AI 判断会话之间的关系并重连（会调模型，有缓存）。
  - **分层**：开/关分层视图。关掉 = 显示**全部对话**的力导向图（老样子）。
  - **柔化**：连线柔化（交叉处断口 / 端点渐隐）。分层下自动关闭。
  - **全览**：缩放到刚好装下全图（打开地图时会自动做一次）。
- 顶部搜索框：点一下或按 `/`，输入关键字，回车**直接定位**（若命中藏在收起项目里的对话，会自动展开该项目并聚焦到它）。

---

## 3. 展开一个项目

**单击某个超级点** → 它：

1. **留在圆心并放大到 1.3×**（表示这是你选中的那个）。
2. 它的对话按**时间**排在**外圈一个环**上：**最新在顶上，顺时针越来越旧**。
3. 最顶上那个（最新）带**浅色光晕**，并被**选择框**框住。
4. 环上最多同时显示 **6 个**；更多的（第 7 个更早的）先不显示，用 ↑↓ 可把它们「转进来」。
5. 其它项目的超级点会被**往外推开**，视图自动居中。

### 在环上挑选（选中 = 选择框里的那个）

| 操作 | 效果 |
|---|---|
| **↑ / ↓** | 转动环：把上一个/下一个转进最顶的**选择框**（点按转 1 个，长按连续转）。 |
| **Enter** | 对「选择框里的那个」执行**聚焦**（见第 4 节）；**再按一次 Enter = 解除聚焦**。 |
| **双击** 某个点 | **打开**这个对话（跳到对话页）。 |
| **单击** 某个点 | **聚焦**它（呼出关联）。 |
| **单击空白** | 解除聚焦（保持展开、视图不动）。 |
| 顶部选择框 | 它固定在最高处；转动环时，转到顶部的那个就是「选中」。 |

> 环上**平时只画「选中/已聚焦」那个对话的连线**，其它点不带线——所以环永远清爽。

---

## 4. 聚焦（看跨项目的关联）

选中（单击点 / 环里按 Enter）某个对话后：

- 环**自动切换**成「它 + 同项目里最相关的 ≤5 个对话」（共最多 6 个）。
- 它在**别的项目**里关联到的对话，会在那些项目的超级点**旁边排成小圈呼出来**；有关联的项目正常显示，没关联的项目**变半透明**。
- 焦点到各关联点之间画连线。
- **单击某个被呼出来的关联点** → 焦点移过去，并**把那个项目展开成整环**（上一个项目自动收起）。
- **解除聚焦**：再按 **Enter**，或**单击空白**。解除后**视图和位置都保持原样**（不重置），并且之后按 ↑↓ 会**按正确的时间顺序接着转**，不会跳序。

---

## 5. 改颜色

- 底部图例每个项目前面的**颜色圆点**：
  - **iPad / 触屏**：点它直接弹**系统调色盘**。
  - **Windows / 桌面鼠标**：点它弹一个**预设调色面板**（18 个低饱和色 + 「＋」自定义 + 「↺」恢复默认）。
- 选好的颜色会**记住**（存浏览器本地），下次打开还在。
- 想换个颜色：再点色点重选即可。

---

## 6. 常用快捷键

| 键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| **↑ / ↓** | 环上转动选择（展开且未聚焦时） |
| **Enter** | 聚焦选中；**再按**解除聚焦 |
| **Esc** | 关掉调色面板 / 提示；清聚焦 |
| **双击** | 打开对话 |

---

## 7. Windows 桌面 / iPad 差异

- **Windows 桌面（鼠标）**：滚轮 = 缩放；**Ctrl+滚轮**不会缩放整个网页（只在图里缩放）；调整窗口大小会自动重新居中。旋转请用 ↑↓ 键（滚轮不再转环，避免误触）。
- **iPad**：双击打开、单击聚焦；旋转用 ↑↓ 键（外接键盘）；触屏双指仍是缩放/平移，不会误转环。

---

## 8. 常见问题

- **界面没更新 / 不对**：iPad 上**关掉 Amadeus 标签页重开一次**（页面会拿新前端）；桌面按 **Ctrl+F5** 强刷。
- **展开后某个对话找不到**：它可能在窗口外（项目超过 6 个对话时）——用 **↑↓** 把它转进来。
- **AI 连线按钮**：会消耗模型调用（有缓存）；不点也能看本地相似度连线。
- **想让某个对话和别的对话连起来**：关系来自「AI 连线」的结果（相似 / 同主题），以及 fork 血缘；点「AI 连线」重新计算。
