# DSH 0.1.7 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Amadeus from DSH `0.1.6-alpha.2` to the latest published DSH `0.1.7-rc.1` while keeping Amadeus authentication, native document patches, plugins, and Docker deployment compatible.

**Architecture:** Keep Amadeus's four Cordis plugins and its DSH startup patch architecture. Pin the DSH packages and matching Cordis/Schemastery runtime dependencies to versions required by `0.1.7-rc.1`; adapt the PDF integration to DSH's shared zoom viewport while retaining Amadeus page navigation. Update the user-facing version references and record the RC status.

**Tech Stack:** Node.js 24, npm workspaces/package-lock, DSH Cordis plugins, Docker Compose.
