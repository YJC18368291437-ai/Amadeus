# Amadeus v1.1.2 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with review checkpoints.

**Goal:** Publish Amadeus v1.1.2 with the installable PWA support, Android/Tailscale bootstrap compatibility, synchronized package metadata, and verified plugin artifacts.

**Architecture:** Keep the existing four Cordis plugins and Docker deployment. Update all project-owned version metadata together, keep the PWA cache namespace aligned with the release, document the user-visible PWA behavior, then regenerate and verify the release packages and running `3080` image.

**Tech Stack:** Node.js 24, npm workspaces, esbuild, Node test runner, Docker, Docker Compose, Tailscale Serve.

**Files:**

Keep the existing `/data` volume, workspace mount, read-only config mount, and `127.0.0.1:3080` binding; retain the previous stopped container for rollback.

Check the Tailscale HTTPS endpoint for the v1.1.2 manifest, service worker, icons, authenticated home page, and protected `/amadeus/ping` route; run a browser check for secure context and service worker control.
